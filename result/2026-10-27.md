## 6. 남은 이슈와 결정 요청

1. **Node 26 전환 여부**: 2026-10-28 Node 26이 Active LTS가 된다. "Active LTS 사용" 원칙을 엄격히 따르려면 Node 26 설치 후 `.nvmrc`·`engines`를 올려야 한다. 현재 의존성은 모두 `>=26`도 지원 범위에 포함된다.
2. **`server-only`와 Worker 분리의 충돌** (구현 보류): CLAUDE.md와 architecture.md §5는 `src/server`의 모든 파일 상단에 `import "server-only"`를 요구한다. 그런데 이 패키지는 React Server 환경 밖(독립 Worker 프로세스, Vitest)에서 import하면 예외를 던진다. engine·llm·events를 Worker로 분리한다는 원칙(절대 규칙 9)과 충돌한다. 제안: `server-only`는 `auth·db·domain·crypto·logging`에만 적용하고 engine·llm·events는 제외한다(문서 3종 갱신 필요). 결정 전까지 패키지는 설치하지 않았다.
3. **호스트 포트 5433**: 이 머신의 5432를 다른 프로젝트 컨테이너(`claude-board-db`)가 쓰고 있어 기본 호스트 포트를 5433으로 정했다. `.env`의 `POSTGRES_PORT`로 바꿀 수 있다.
4. **Prisma 업데이트 안내 문구**: `prisma` 명령 실행 시 `latest`(8.0.0 RC)로 업데이트하라는 안내가 나오지만 무시해도 된다. 안정판이 나오면 별도 작업으로 올린다.
5. 이 보고서(`result/2026-10-27.md`)는 아직 커밋하지 않았다.
